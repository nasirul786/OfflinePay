Questions

Does it really work without internet?

Yes. OfflinePay uses *99#, NPCI's USSD service for UPI. USSD travels over the regular mobile network, the same way a call does, so you need network signal but no mobile data or Wi-Fi.

Why does OfflinePay need the Accessibility permission?

*99# shows its steps in a system dialog. OfflinePay uses Android's Accessibility Service to read that dialog and fill in each step for you, such as the payee, the amount and your PIN. It is active only while a payment you started is running, and it ignores every other app.

Is my UPI PIN safe?

Your PIN is kept in memory only for the payment you're making. It is typed into your bank's *99# dialog and discarded as soon as that payment ends. It is never written to storage or sent anywhere else.

Which banks and operators are supported?

Any bank and mobile operator that supports UPI over *99#. That includes most major Indian banks and operators.

How do I install it?

Download the APK from the latest GitHub release and open it. If Android asks, allow your browser or file manager to install unknown apps. Then open OfflinePay and follow the setup steps.

Is there a fee?

OfflinePay is free and open source. Your mobile operator may charge up to ₹0.50 per *99# session, as allowed by TRAI. If it helps you, you can support the project.

The service stopped working on my Xiaomi, Redmi or POCO phone

These phones close apps in the background to save battery. In OfflinePay, open Settings → Background, allow Autostart, and set Battery saver to No restrictions. Then turn OfflinePay off and on again under Accessibility.
